Live server update — step-by-step (copy each block)

Use this after the developer pushes the new code to main. Open each step, click Copy, paste into your terminal (Mac Terminal or PuTTY on Windows). Do the steps in order.

Step 1

Connect to the VPS (SSH)

On your computer, open Terminal and run this command. Press Enter.

ssh root@2.24.94.60
Step 2

Enter VPS password

When asked for password, paste the password below (nothing will show while typing — that is normal). Press Enter. 

12345678Na@#

This is the Hostinger VPS root password, not the admin website login.

Step 3

Go to the project folder

After login, you should see a server prompt. Run:

cd /var/www/player-paradise
Step 4

Download latest code & build (after developer push)

Run this one line. Wait until it finishes (may take a few minutes).

git pull origin main && npm install && npm run build
Step 5

Open the .env file (nano editor)

To set or change the admin website password, open the environment file:

nano .env
Step 6

Add or update admin lines in .env

In nano, scroll with arrow keys. If these lines already exist, change only the values after =. If they are missing, paste at the bottom of the file. Current admin portal password (for https://playersparadisehub.com/admin) is in ADMIN_PASSWORD below. 

ADMIN_EMAIL=admin@playersparadisehub.com
ADMIN_USERNAME=superadmin
ADMIN_USERNAME_ALIAS=admin
ADMIN_PASSWORD=Paradise@2026!
Admin login after restart:
URL: https://playersparadisehub.com/admin
Username: superadmin or admin
Password: Paradise@2026! (or whatever you set in ADMIN_PASSWORD)
Step 7

Save and exit nano

Do these keys in order (hold Control and press the letter):

1) Press Ctrl+O  then Enter  (save file)
2) Press Ctrl+X  (exit nano)

On Mac: Ctrl+O, Enter, then Ctrl+X

Step 8

Restart the live website

Back at the normal server prompt (not inside nano), run:

pm2 restart all && pm2 status

When status shows online, open the site and test admin login.
